# Security Policy

## Reporting a Vulnerability

If you discover a security issue related to authentication, cookies, credential handling, or downloaded content, please report it privately instead of opening a public issue.

Until a dedicated security contact is configured, avoid posting:

- CAUTH cookie values
- Coursera usernames or passwords
- Browser session cookies
- Personal access tokens
- Private course material

When reporting an issue, include:

- Operating system
- Python version
- coursera-helper version
- Reproduction steps
- Sanitized logs and stack traces

Please redact all credentials and session information before sharing logs.

## Supported Versions

Security fixes are currently applied to the `main` branch only.
